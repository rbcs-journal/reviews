# 🔍 RBCS Reviews — Repositório de Revisão por Pares Aberta

Bem-vindo ao repositório de revisão editorial da **Revista Brasileira de Computação e Software Científico (RBCS)**.

Este repositório é o núcleo operacional da revista. Aqui, todo o processo de submissão, triagem (*pre-review*), revisão por pares e recomendação de aceite é conduzido publicamente através de **GitHub Issues**.

---

## 🚀 Como Submeter um Artigo

1. Vá para a aba **[Issues](https://github.com/rbcs-journal/reviews/issues)**.
2. Clique no botão verde **"New Issue"**.
3. Selecione o template **"📝 Nova Submissão de Software"**.
4. Preencha as informações do repositório, versão, autores e trilha editorial.

---

## 🛠️ Comandos Úteis nos Issues

Autores, revisores e editores podem interagir com a automação editorial através de comentários nos issues:

| Comando | Descrição |
| :--- | :--- |
| `/compile-pdf` | Dispara o compilador **Inara** para gerar uma prévia em PDF do artigo do autor. |
| `/preview` | Alias para `/compile-pdf`. |
